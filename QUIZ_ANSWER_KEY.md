# QUIZ answer key (do not read before attempting `QUIZ.md`)

1. State = (mode, cell) over a 40x40 grid, plus a scalar `outside`. Modes: 0 = stopped, 1..8 = moving at heading 0,45,...,315 degrees. `outside` = probability the subject has left the search area (absorbing). Grid mass + outside = 1 always. (`beliefview/belief.py`)
2. posterior(state) = prior(state) * (1 - P(detect | state, view)) / Z, with Z = sum over all states (incl. outside) of that numerator. Behind an opaque obstacle line of sight is blocked, so P(detect)=0 and the cell only changes by the common 1/Z factor (it grows slightly because mass elsewhere shrank). Foliage multiplies P(detect) by `foliage_factor` (0.4 assumed), so 1-P is closer to 1 and the cell loses less than a clear cell at the same range/bearing. (`tests/test_belief.py`: clear/behind/foliage/analytic tests)
3. Multiplying by likelihoods removes probability mass (the chance of the miss), so dividing by Z makes the total 1 again. The subject outside the area cannot be seen, so P(miss | outside) = 1 and its likelihood factor is 1; its *share* rises after a miss. Tests assert `b.sum() + out == 1` after every predict/update, nothing inside opaque cells, and non-negativity.
4. Independent-look gating (`LookTracker`, `look_period=3`): if the pose is unchanged (position within 0.25, yaw within 10 degrees) a new look, with its own detection chance and miss update, happens only every 3rd step; the steps in between give no evidence. Test: 30 staring steps produce 10 miss updates, and a naive filter that counted all 30 is shown to be more over-confident. Limitation: this is an assumption about sensor correlation, not a measured fact.
5. Assumed: a moving subject within 2 units of the boundary leaves with probability `edge_exit_rate` (0.03) per step; in addition any predicted motion that crosses the boundary moves that mass to `outside`. Scenario D has a true hazard of 0.08 and many exit-bound subjects; the sweep reruns BeliefView with assumed rates 0, 0.01, 0.03, 0.08, 0.2 on the *same* episodes and reports reacquisition, correct/false "left the area" calls and the stated-vs-actual outside fraction.
6. Candidates: hold position with 8 yaw choices, plus travel to free cells at 4, 8, 12 units in 8 directions, each holding either the travel heading or a heading toward the belief centroid; reachable only if the shared speed/turn-limited, collision-checked controller arrives within the horizon (12 steps). For each, the belief is predicted step by step and the expected miss update applied at each independent look; benefit = P(reacquire within the horizon); score = benefit - lam * travel steps. In the v2 (headline) run lam = 0.004: one shared, strictly positive value, chosen on 100 new validation episodes in each of scenarios A and B as the largest of {0.0005, 0.001, 0.002, 0.004} whose combined reacquired fraction (0.605) was within 0.03 of the grid's best (0.620), and shared unchanged with the ablation. What it bought is measured against a lam = 0 reference arm on the same final episodes (see README; the reference arm is not a headline). In the earlier v1 record validation picked lam = 0, so the travel cost was inactive there. It picks the single best candidate, executes 3 steps, observes, updates and replans: a one-step lookahead (greedy), with no search over sequences, so not globally optimal.
7. Stay-in-place (camera scans), go to the last-seen point then scan, fixed orbit around the obstacle nearest the last-seen point, and the same planner without miss updates. All share the map, the identical pre-rolled subject trajectory and per-step detection uniforms, sensor, look gate, observer speed/turn limit/collision controller and deadline; only the decision rule differs. (The uniforms are shared, the observations are not: what a policy sees depends on where it is looking.) The ablation uses the same planner settings as BeliefView and differs only in skipping miss updates, so it isolates whether the negative information (misses) is what helps.
8. Structural: inference modules (`belief.py`, `planner.py`, `policies.py`, ...) never import `world.py`/`runner.py`; policies only receive `Observation` objects (pose, look flag, detected flag, noisy z) and the noisy last-seen measurement/age. Tests: AST import and attribute checks, and a metamorphic test where two different hidden truths with an identical observation stream (all misses) yield identical drone paths and beliefs.
9. Reacquired = first positive detection (the sim has no false positives, so detection = true subject). A search that hits the deadline without detection is censored at T; averaging only successes would reward policies that find only the easy cases. We report the cumulative reacquired curve, fraction by T, unresolved fraction, and restricted-mean search time with timeouts counted at T. Paired bootstrap resamples the same episodes for both methods to get 95% intervals on the *difference*.
10. See "Failures and honest limitations" in `docs/TECHNICAL_REPORT.md` (summarised under the same heading in `README.md`) for the measured mismatch result you chose. Limitations of the 2D sim: no real vision/perception errors (no false positives, no clutter), no 3D altitude/gimbal, simplified kinematics (no wind, latency, battery), a single fixed map, abstract subject behaviors, opaque rectangles with hard line-of-sight edges.
